# 🎓 AI VIVA MASTER

AI VIVA MASTER is a Python and Streamlit based application
designed to help students practice viva questions.

## Features

- Subject-wise viva questions
- Python, Machine Learning, AI, Data Science and Java
- Different difficulty levels
- Multiple viva questions
- Answer submission
- Automatic scoring
- Question-wise results
- Final score and percentage
- Restart viva option

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NLP libraries
- AI/ML libraries
